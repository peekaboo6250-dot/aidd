# 接入真实数据与模型前的门槛

## 靶点筛选
当前 DEMO_A/B/C 均为虚构样例，不预设最终靶点。评分范围0–5，
priority = 0.5×疾病证据 + 0.3×活性数据可用性 + 0.2×结构可用性。
这些权重是可修改的工程默认值，未进行科学验证。

真实证据表应逐项记录：人类肾组织/单细胞表达、遗传或干预证据、肾纤维化动物验证、
细胞类型、作用方向、PMID/DOI、来源URL、检索时间、结构PDB/口袋、
ChEMBL/BindingDB靶点ID、独立化合物与同质活性端点数量。
不要把数据库记录数当作独立抑制剂数量；待核实证据不可填成已证实。
与线粒体转移相关的机制分子不自动具备小分子可成药口袋。

## 三类接口
- AIDocking：真实调用前需 receptor、口袋、构象/质子化策略、checkpoint、引擎版本，
  输出score、units、compound_id、backend；当前调用明确抛出NotImplementedError。
- GNN：需要训练/验证/测试集、图特征定义、任务与标签单位、训练权重，
  输出同样必须带ID和单位；MockGNN只是恒值fixture。
- EnsembleUncertainty：对同一任务、相同单位和相同化合物的多个成员预测计算均值/样本标准差；
  本版只接收数值向量，调用方负责按ID对齐。标准差不是校准置信区间。
  不得直接把对接能量与GNN活性预测求平均或求方差。

## 后续真实基准
先建立一个有可用结构和同质测定标签的靶点小集合（100–1000个分子），
按规范化结构与骨架隔离划分，检查近似物泄漏；若数据允许增加时间外推划分。
分类报告PR-AUC、ROC-AUC、EF1%与bootstrap区间；回归报告MAE、RMSE、Spearman。
小集合的EF1%很不稳定，需报告入选数及活性比例。对接先做共晶重对接并记录重原子RMSD，
再评价活性物富集；有监督GNN需与指纹+传统模型比较。
对不确定性评估误差-不确定性关联、覆盖率和risk-coverage，单独保留校准集。
方法创新需通过独立测试与消融验证，不能以简单组合多个模型作为结论。

未来模型候选由其官方安装说明、权重许可和实测显存决定；此版本故意不绑定某个CUDA框架。
所有真实运行均应记录权重hash、随机种子、数据划分、驱动/CUDA/PyTorch版本、耗时与峰值内存。
